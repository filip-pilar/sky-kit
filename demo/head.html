sky-kit

Endless drifting painterly clouds on a bright blue sky. A real cloud near the chosen spot reshapes into a word, emoji or symbol, holds it, then melts back into itself. This page is a live demo; its Code tab gives the code for the settings you pick.

Source and docs: https://github.com/filip-pilar/sky-kit (MIT). Agents: read README.md there first, then AGENTS.md for working on the code.

Web: one ES module with no dependencies and no build step, WebGL2. Import https://cdn.jsdelivr.net/gh/filip-pilar/sky-kit@v0.3.2/web/src/sky.js or copy web/src/sky.js. createSky(container, options) returns set, pause, play, flyPlane, showShape, releaseShape, clearShape, shapeState, snapshot, destroy. React: web/src/react.js.

Swift (iOS 16+, macOS 13+): .package(url: "https://github.com/filip-pilar/sky-kit", from: "0.3.2"), then SkyView(options, controller: SkyController()).

Tapping the sky forms the words on the tapped cloud; up to three shapes are up at once (showShape's id option). Links to this page can carry words: the address ending #happy-birthday--sam forms "happy birthday", then "sam".

sky-kitdrifting clouds for the web and SwiftCode on GitHub ↗

Tap clouds to form the words (or the last symbol) on them, up to three at once. Commas chain words: each forms on the same cloud after the last melts. Pause 0 turns one word straight into the next. Hold ∞ keeps it until Melt now.
